# 原生三次与五次走廊的性能结构分析与加速实施计划

后续实现与测量见[第五轮生成实验](原生三次走廊冗余约束与Newton内核优化.md)。
参考源码已经冻结为 `f72f3fe`；有证明的约束压缩、精确内核、替代障碍与初值
实验已落实，延迟曲率进行了首轮比较。当前按用户调整后的目标，只用走廊的
生成速度、并集体积、几何平滑性和连续安全性选型，轨迹优化不作为本阶段门槛。
局部块修正、按需进度约束和细分证书增量复用仍待实施。以下保留原分析与计划。

2026-11-04，分支 `experiment/native-cubic-minjerk`。分析对象是 round4 的原生
C3 平衡配置和 H5-S；分析时的源码包含尚未提交的 round3、round4 修改。本次新增结构诊断，
没有修改生成器，也没有把诊断中的约束删减数量当作生成加速结果。

**单独降阶确实更快。当前完整生成没有普遍超过 H5，主要因为换参数化后，进入
Newton 的约束更多、单行关联更多节点，初始化和障碍函数也发生了变化。**
带宽是原因之一，但目前线性求解只占 C3 总耗时的约 7%–9%；优先方向应当是
减少实际参与优化的约束、降低装配成本，以及改善初值和有效步长。

## 1. 把次数的影响与生成算法的影响分开

已有实验将同一条三次曲线精确升阶成五次，然后在相同细分深度计算支持上界。
七例各自取正式重复中位数，再取场景间时间比的中位数，结果为：

| 细分深度 | 三次 / 五次支持上界计算时间 | 三次减少的时间 |
| --- | ---: | ---: |
| 0 | 0.674 | 32.6% |
| 1 | 0.683 | 31.7% |
| 2 | 0.689 | 31.1% |
| 3 | 0.681 | 31.9% |

这是同几何的支持上界内核实验，不是完整生成、完整安全认证或轨迹优化计时。
升阶还可能收紧控制凸包，因此两种表示的支持上界数值不必相同。

完整生成采用冻结输入、一次预热、21 次正式重复、固定 CPU 2。七例耗时中位数
之和为 H5 246.25 ms、C3 255.16 ms，C3 多 3.6%；其中两条迷宫路径分别快
18.3% 和 9.3%，其余五例慢 8.7%–13.7%。C3 的并集体积比 H5 大约 1.0%–7.9%。
它已经有场景优势，目前的问题是优势还不稳定。

## 2. 五次的六个控制量，并不意味着六份优化工作

H5 的主优化阶段使用权重

$$w=[0,0,0,1,1,1].$$

中心控制量是固定参考项加左右节点偏移；形状控制矩阵是

$$[M_i,M_i,M_i,M_{i+1},M_{i+1},M_{i+1}].$$

对同一支持平面，前三行具有完全相同的变量系数，只有固定参考中心造成的
右端项不同。因此保留最严格的一行即可；后三行同理。没有细分时，六个
Bézier 支持约束往往变成两个单节点约束。细分后的混合行另行处理。

实现见 [Patch、controls 和 ShapeCertificates::add](../direct_corridor/src/hermite_optimizer.hpp)。
之后还会跨区间合并相同行，并对单节点约束做二维极坐标凸包去冗余。

C3 的均匀内部区间则是

$$
Q_0=(P_0+4P_1+P_2)/6,\quad Q_1=(4P_1+2P_2)/6,
$$
$$
Q_2=(2P_1+4P_2)/6,\quad Q_3=(P_1+4P_2+P_3)/6.
$$

四行通常具有不同的变量系数。常见行关联两个或三个控制点，受限子区间还能
关联四个，不能像 H5 那样直接六并二。当前 C3 已经清零提取矩阵中的代数零项，
也已合并共享边界行；这些不是尚未实施的新优化。

H5 最后通过 `smoothSweep()` 求共享导数、按安全余量调整并重新扩张，所以
**最终 H5-S 并不是形状导数仍全为零**。便宜的是它主优化时的变量结构。

三次多项式不能在任意不同的端点值下，同时指定两端的一、二阶导数为零：
这是六个条件，而三次只有四个系数。把 H5 的零导数结构直接移到三次，会
损失 C² 或表达能力。五次在这里用额外的次数换来了便宜的主优化结构。

## 3. 实际约束数与耗时证据

原 H5 日志中的 `constraints` 是去冗余前的行数。本次调用同一 H5 生成器，
补读 `metrics.active_constraints`，得到最后一次优化实际保留的行数。
这里的 active 指参与求解的行，不等同于最优点处取等号的 KKT 活跃约束。

| 场景 | H5 原始行 | H5 保留行 | C3 求解行 | C3 / H5 保留行 |
| --- | ---: | ---: | ---: | ---: |
| 0 | 4560 | 2387 | 8683 | 3.64 |
| 1 | 8566 | 3791 | 16990 | 4.48 |
| 2 | 5161 | 3001 | 9199 | 3.07 |
| 3 | 8046 | 3731 | 15141 | 4.06 |
| 4 | 4152 | 2117 | 8226 | 3.89 |
| 5 | 3709 | 1817 | 7374 | 4.06 |
| 6 | 5155 | 2590 | 9560 | 3.69 |

这是末轮问题的结构对照，不是整个生成过程累计行求值次数。C3 的行数包含
369–1406 条固定法向进度约束；其他为几何支持约束。

以场景 1 为例，H5 总耗时 49.00 ms，C3 为 55.71 ms：

| 阶段 | C3 / ms |
| --- | ---: |
| 障碍查询 | 3.38 |
| 分离面生成 | 14.44 |
| 优化问题准备 | 3.03 |
| 梯度与 Hessian 装配 | 18.53 |
| 带状分解及回代 | 4.22 |
| 可行步长与线搜索 | 7.67 |
| 生成过程中的 Jacobian 检查 | 0.79 |
| 最终复核 | 0.37 |

各阶段独立取重复中位数，表中没有列出所有杂项，因此不要求逐项相加严格
等于总耗时。H5 的整个优化阶段为 20.47 ms；C3 的装配、求解与线搜索合计
30.42 ms。C3 的装配和线搜索占总时间约 47%，七例范围为 39.6%–49.5%。

H5 的 `certificate_ms` 为 24.72 ms，但它包含障碍查询、分离等工作，不能
直接拿它与 C3 的最后 0.37 ms 复核比较。

即使场景 1 的带状求解快一倍，也只节省约 2.11 ms，小于 6.70 ms 的总时间
差距。继续只打磨求解器、最后一次认证或普通多项式求值，抓不到主要成本。

## 4. 优先借鉴 H5 的约束去冗余，但需要适配 C3

H5 的单节点形状完全位于同一个二维标架内，二维半平面去冗余便宜且有效。
C3 混合多个不同标架后，可达空间一般是三维。本次检测七例的 497–938 个
约束组，只有 2–15 组在数值上满足二维结构。因此不能简单把所有法向投到
二维，再照搬 H5 删除约束。

已有 C3 三维 QuickHull 去冗余实验删除了很多行，却因准备开销和优化路径
变化而变慢。另一个实现问题是，当前 `prepareLine()` 和 `feasibleStep()`
仍扫描所有几何行，即使某行已被证明冗余；只在代价装配时跳过不够。

### 二维候选与原三维模型的冗余证明

可以用二维投影快速寻找候选，再用原三维可达范围证明候选确实冗余。
对同一个控制截面组，记

$$c=c_{ref}+\sum_i A_i d_i,\qquad M=\sum_i A_iS_i,$$

其中 $\|d_i\|\le d_{max}$，$0\prec S_i\preceq r_{max}I$。
取组内严格可行的参考中心 $c_0$，将平面归一化为

$$q_j=\frac{n_j}{b_j-n_j^Tc_0},\qquad q_j^T(y-c_0)\le1.$$

用二维投影凸包寻找两个保留顶点 $q_a,q_b$，使投影满足非负组合
$\lambda q_a+\eta q_b$，且 $\lambda+\eta\le1$。实际三维残差为

$$e=q_j-\lambda q_a-\eta q_b.$$

对所有可行变量及 $\|z\|\le1$，有

$$e^T(c+Mz-c_0)\le e^T(c_{ref}-c_0)
 +(d_{max}+r_{max})\sum_i\|A_i^Te\|.$$

因此，只要

$$\lambda+\eta+e^T(c_{ref}-c_0)
 +(d_{max}+r_{max})\sum_i\|A_i^Te\|<1,$$

被检查平面就由保留平面和已有变量边界蕴含。投影只负责找证明的候选，
接受条件仍在原三维模型中成立。诊断采用 $10^{-10}$ 的余量，且每个删除证明
只引用一直保留的凸包顶点，不产生循环依赖。

| 场景 | 几何支持行 | 满足充分删减条件的行 | 比例 |
| --- | ---: | ---: | ---: |
| 0 | 8278 | 3226 | 39.0% |
| 1 | 15584 | 4014 | 25.8% |
| 2 | 8830 | 3146 | 35.6% |
| 3 | 13854 | 4237 | 30.6% |
| 4 | 7650 | 2767 | 36.2% |
| 5 | 6942 | 2103 | 30.3% |
| 6 | 9056 | 3506 | 38.7% |

这是冻结最终几何及支持平面的结构诊断，尚未测量生成流程中的净加速。
集成时要在每次构造的新问题上建立证明，并把已证明冗余的行同时移出
装配和步长扫描，原始行保留用于阶段末审计。启发式 working set 丢掉的行
不能享受同样待遇。即使可行域相同，删掉障碍项也会改变有限 $\mu$ 的优化
轨迹，因此仍要比较最终体积和轨迹质量。

## 5. 借鉴 H5 的低秩曲率，同时分清障碍函数

令 $d=b-n^Tc$、$w=M^Tn$、$r=\|w\|$。H5 使用

$$\phi_H=-\mu\log(d-r),$$

C3 使用正分支上的 Lorentz 锥障碍

$$\phi_C=-\mu\log(d^2-r^2)
 =-\mu\log(d-r)-\mu\log(d+r).$$

两者可行域相同，有限障碍参数下的中心路径、梯度与曲率不同。因此相同的
迭代预算、同样写作 `0.003` 的障碍参数，并不意味着相同的优化精度。
C3 还按控制点数量归一化参数，并使用基函数积分作为 logdet 权重。

Lorentz 障碍是标准光滑构造；它不是实现错误。直接对范数支持余量取对数，
在 $w=0$ 时需要区分线性退化项和非光滑项。
[UCLA 内点法课程资料](https://www.seas.ucla.edu/~vandenbe/ee236b/lectures/barrier.pdf)
给出了这类二阶锥障碍及范数表达的光滑性区别。

当 $r>0$ 时，记 $s=d-r$，有

$$\nabla^2\phi_H=\frac{\mu}{s^2}\nabla s\nabla s^T
 +\frac{\mu}{sr}J_w^T(I-\hat w\hat w^T)J_w.$$

$w$ 是二维向量，第二项至多秩一，所以每个支持约束只需两个秩一更新。
H5 已经直接把它们写入 5×5 块，且大量行只触及一个节点。

值得做两组独立实验：一组保持 Lorentz 障碍不变，只优化低秩装配及 2/3/4
节点专用内核；另一组固定 C3 模型、平面、初值和主目标，比较两种障碍函数。
几何支持项与进度锥也可以分别选择合适的表达。验收使用相同物理可行性和
归一化残差，不能只比较固定迭代数。

当前 C3 的九维分组装配会摊薄同组多个平面的映射成本，直接逐行写 5×5 块
未必更快。标量支持障碍在线搜索中还可能多出范数开方，不能仅由秩二推断
整体收益。

## 6. 借鉴 H5 的初值与分阶段策略

H5 在第一次 Newton 之前，根据已经生成的支持平面求可行圆半径，并保留
约 15% 的余量。C3 当前主要使用最近障碍球净空的 65% 初始化；这个距离
没有充分利用障碍的方向性。

应尝试在当前支持平面下，先做解析半径扩张或少量五维局部更新，再进入
完整耦合 Newton。初值保留与当前障碍阶段相匹配的内部余量，避免先推到
边界，再花迭代重新向内居中。

此前 C3 的 `inflate()` 放在完整求解之后，径向再扩张的体积收益小于 0.1%。
这不等于同类廉价更新放在 Newton 之前也没有价值：前者补体积，后者可能
减少后续重装 Hessian 的次数。必须分别实验。

七例 C3 的平均接受步长约 0.11–0.25；这说明全局方向经常被局部紧约束缩短，
但尚无 H5 步长统计，不能直接断言 H5 的步长更大。可以尝试局部控制点块
更新或重叠子域修正，再用少量全局 Newton 协调。更新同一组全局 B 样条
控制变量会自动保持 C²，不需要另做拼接。

## 7. 后续算法选择与优先级

| 优先级 | 方法 | 主要减少的工作 | 关键对照 |
| --- | --- | --- | --- |
| P0 | 可证明的约束压缩，连同步长扫描一起删除 | 每步行数、装配和线搜索 | 包含压缩准备时间，复核原始支持行 |
| P1 | 低秩及依赖节点数专用内核 | Hessian 装配 | 固定相同障碍函数、梯度和几何 |
| P1 | H5 风格支持余量障碍 | 曲率与中心路径成本 | 单独控制障碍差异，处理零范数 |
| P1 | 平面感知初始化，再做全局 Newton | 重型迭代次数和短步长 | 与末尾 refill 分开；保持连续认证 |
| P2 | 精确完整梯度，弱约束曲率延迟更新 | Hessian 重装频率 | 保留完整代价与可行步长，记录迭代增加 |
| P2 | 按 Jacobian 证书裕量选择进度约束 | 不必要的进度行 | 修复成本和失败率计入总时间 |
| P3 | 已接受几何的证书复用 | 重复末尾认证 | 只在几何或覆盖变化时失效 |
| P3 | 带状分解小矩阵内核、精确插入后的粗到细求解 | 求解常数、局部自由度 | 避免通过丢体积换速度 |

弱约束曲率延迟更新与目前的 working set 不同：仍计算完整梯度 $g$，只以
正定近似 $\widetilde H$ 替代每次重装的 Hessian。方向

$$p=-\widetilde H^{-1}g,\qquad g^Tp<0$$

仍是下降方向，用完整目标进行线搜索。它保持目标和约束不变，但可能增加
迭代数，收益取决于节省的装配成本是否超过额外更新。

当前已有 BVH 和查询缓存、解析可行步长、SPD 边界处理、能量矩阵复用、
共享支持合并、带状尺度平衡、延迟障碍排序。重复提出这些不算新的加速方向。
同点 SOC 值缓存、普遍缩减迭代、简单粗化 knots、原样三维 QuickHull 和
粗粒度 working set 此前均没有稳定胜出，需要改变具体机制后再评估。

先固定平面和模型测试计算内核，再测整个生成流程；最终仍使用冻结七例、
相同连续证书、同序列 QMC 体积和同初值轨迹后端。需要继续覆盖独立场景，
才能判断这些结构改进是否能把 C3 的局部优势变成普遍优势。

## 8. 分阶段实施计划

以下阶段按顺序实施，先完成单项对照，再组合已经证明有效的方法。当前已经
完成性能分析和约束冗余诊断，生成流程的改造从阶段 A 开始。每个阶段单独
保存代码、配置和结果，便于区分收益来源。

### 阶段 A：冻结参考版本并补齐计量

先保存当前 round4 的 C3 与 H5 可执行文件、编译选项、源码哈希及工作树差异，
在实施算法改动前单独提交当前生成代码。参考配置保持 0.4 m 间距、65% 净空
初始化、两轮扩张，每轮 8 / 4 / 4 次 Newton 预算；继续启用能量矩阵复用和
延迟障碍排序。

在 `benchmark.cpp` 和统一报告中补充下列指标：

| 指标 | 记录方式 |
| --- | --- |
| 约束数量 | 每轮分别记录原始行、合并行、证明冗余行、实际求解行和进度行 |
| 约束工作量 | 累计记录梯度、Hessian、步长边界、线搜索代价各自处理的行数 |
| 准备成本 | 单列冗余证明、分组映射、能量准备和初值扩张耗时 |
| 迭代效果 | 记录每步接受步长、步长限制来源、障碍参数、Newton decrement 和终止状态 |
| 装配与求解 | 分开记录梯度、Hessian、分解、回代以及曲率重建次数 |
| 认证 | 记录支持与 Jacobian 的调用次数、细分数、复用次数和最终裕量 |

H5、C3 同时报告原始与保留行数。日志按阶段汇总，不在约束内循环输出文本；
先测量计量开关自身的影响。数据格式和有限性在入口校验，内部使用已构造好
的索引与变量范围；连续几何证书属于算法必要工作，按阶段执行。

**验收：** 新计量不改变输出系数和终止状态，能够重新解释七例各阶段总开销，
并区分约束减少、单行变快和迭代减少三种收益。

### 阶段 B：有证明的约束压缩贯穿整个求解器

在 `CubicProblem` 构造阶段集成第 4 节的投影候选与三维残差界。为每个组建立
稳定的原始行编号、保留行列表和冗余证明关系。证明引用的凸包顶点始终保留；
支持平面、提取映射或变量范围改变后重建证明，普通 Newton 更新不重复构建。

修改 `cubic_optimizer.cpp` 的装配和 `feasibleStep()`，以及
`cubic_refinement.cpp` 的 `prepareLine()`，使它们使用同一份压缩后的行列表。
原始支持平面供阶段末完整认证使用。证明删除与启发式工作集保持不同状态，
后者仍参与可行步长约束。

实验分为无剪枝、现有三维 QuickHull、投影证明只用于装配、投影证明覆盖装配
与步长四组。这样可以直接量出省掉线扫描的价值，以及证明准备是否抵消收益。

数值测试覆盖相同标架、混合标架、近共面、近平行法向、原点位于投影凸包边界
和很小支持余量。检查每个删除证明的充分不等式及其保留依赖，再用原始行验证
求解结果；对小规模问题增加独立可行域搜索，辅助排查误删。

**验收：** 全部连续证书通过，完整生成耗时包含压缩准备；体积和轨迹比较满足
第 9 节的采用条件。26%–39% 是最终快照上的诊断比例，实际每轮比例单独报告。

### 阶段 C：分开研究装配内核与障碍函数

首先固定现有 Lorentz 障碍、支持平面、控制变量和迭代点，比较九维分组装配与
按 2/3/4 节点依赖专门实现的低秩块装配。基函数映射、非零块位置等常量在
问题建立时预计算，避免每步重新判定稀疏结构。保留参考实现作数值对照。

内核通过后，再独立比较几何支持项的 `-log(d-r)` 和 `-log(d²-r²)`。进度项
可以继续采用光滑 Lorentz 障碍。对零范数的线性退化项作解析处理；一般的
零范数点不能用随意截断范数代替原问题，需要保持与声明的目标一致。

**验收：** 相同目标的内核比较通过值、梯度及 Hessian-vector 对照；有限差分
覆盖随机内部点、窄余量和不同依赖节点数。障碍函数比较同时报告固定预算和
匹配最终可行性及归一化最优性残差两组结果，避免把不同中心路径混作内核收益。

### 阶段 D：支持平面感知的原生初始化

在 `cubic_generator.cpp` 中第一次获得可行支持平面后、完整 Newton 之前，
加入解析半径扩张或少量五维控制点块更新。更新使用当前支持约束、变量上下界
及已有进度约束，保留与起始障碍参数相匹配的内部余量；阶段末完成连续认证。

比较四组：现有净空初始化、前置解析扩张、前置局部块更新、现有末尾 refill。
局部更新先扫描 1/2/4 轮预算，记录准备成本、有效步长和后续 Newton 次数。
初始对照保持原 Newton 预算，确认几何收益；随后按共同残差门槛评估是否能
减少重型迭代。控制变量仍是原生三次 B 样条，不引入 H5 生成成本。

**验收：** 初始化及修复时间计入总时间，成功率不降低；完整生成达到相同质量
时更快。新初值变大本身不作为采用依据。

### 阶段 E：延迟弱约束曲率、局部修正与按需进度约束

在前面阶段的优胜配置上分别实验三个开关。弱约束曲率延迟更新保留完整目标
和精确梯度，仅复用正定曲率近似；根据支持余量的相对变化及方向效果决定重建。
若下降或分解条件不满足，回到精确装配。记录节省的 Hessian 工作及额外迭代。

局部块更新单独比较，用来处理少数区间限制整条走廊步长的情况。按需进度约束
则依据局部 Jacobian 证书结果添加，在每次几何修改后完成必要的连续认证，
并将修复、回退与失败全部计入耗时。先分别验证，再做组合，避免参数相互掩盖。

**验收：** 完整梯度、目标下降与连续安全保持原语义；任何节省都由端到端时间
确认，不能仅依据 Hessian 重建次数或进度行数宣布提升。

### 阶段 F：组合验证和剩余小项

优先组合约束压缩、最优装配内核与前置初始化，保留单项开关做消融。对有明显
交互的两项增加四组合对照；不把几个单项百分比相加作为预期总收益。

随后复用已经通过认证且几何和覆盖均未变化的结果，按对象修改边界失效缓存。
带状小矩阵内核和精确 knot 插入后的粗到细求解放到最后，避免在低占比部分
投入过多，或让节点变化掩盖前面实现的收益。

每阶段形成一次可复核提交，包含实现、必要测试、原始数据和结论。未形成稳定
收益的方法保留为实验选项，并记录未采用的原因。

## 9. 统一实验协议与采用条件

| 项目 | 固定方式 |
| --- | --- |
| 参考输入 | 冻结七例地图、种子路径、地图边界与哈希；H5-S、round4 C3 为双参照 |
| 安全模型 | 0.25 m 体素外接球、0.20 m 机器人、0.05 m 安全余量、0.002 m 证书余量 |
| 几何配置 | 3.0 m 扩张范围、7.0 m 长边切分、主比较 0.4 m 控制间距 |
| 执行资源 | 编译与实验串行，单任务 4 GiB 地址空间上限，数值库单线程 |
| 正式计时 | 固定 CPU 2，一次预热、21 次正式重复；交替参照和候选顺序 |
| 时间范围 | 热路径完整生成与含 BVH 构建的冷启动分开，包含所有准备、修复和复核 |
| 体积 | 同一采样域、8 组随机平移 QMC、每组 65,536 点，按场景配对 |
| 轨迹 | 同一五次最小 jerk 后端、初值及其哈希、时长、动力学参数和代价权重 |
| 扩展验证 | 优胜配置覆盖历史 26 条路径和预先冻结的独立场景，独立场景不参与调参 |

固定模型、平面和变量点的微基准用于定位计算收益；只有完整生成和轨迹结果
用于选择默认方案。报告每例完整时间序列、中位数、P95、CPU 和峰值 RSS，
同时记录成功、超时、初始化失败和数值失败，失败例保留在总体统计中。

采用条件如下：

1. **连续安全。** 原始完整支持平面、世界与局部边界及全截面 Jacobian 证书
   全部通过；C² 与非退化条件保持。不能用轨迹采样代替走廊连续认证。
2. **等价内核。** 只改变计算组织时，目标、梯度、Hessian-vector 和几何在相应
   浮点误差范围内一致；对窄余量问题单独报告尺度和误差，不依赖单一绝对阈值。
3. **几何质量。** 改变优化路径时，对比并集体积、最窄半轴、弯曲能量和 Jacobian
   裕量。体积差接近 1% 时增加配对采样并给出误差区间；有明确体积退化的配置
   作为速度—质量取舍保留，不替换当前默认。
4. **轨迹质量。** 记录可行率、约束违反量、目标值、轨迹时长、优化时间和迭代数。
   冻结七例当前 C3 的采样验收为 5/7；同时保留每例身份和失败余量，不能通过
   一例变好、另一例变坏维持相同计数来宣称没有退化。
5. **实际加速。** 比较完整生成及“走廊生成 + 轨迹优化”总时间。采用稳定超过
   测量波动的收益；若准备成本抵消迭代收益，则保留结果而不启用为默认。

最终目标是在连续安全与现有 C3 质量下稳定超过 H5。七例中位数总和是辅助
汇总，仍要展示逐场景分布、尾部耗时和独立场景结果。
