# H5 生成链路清理

C3 清理先提交为 `884f9cd`。本轮整理 H5 的生成器与其形状阶段接口。

- 删除未采用的跨膨胀障碍参数跳阶段策略，清除 `continue_barrier`、`barrier_begin` 及关联调用。保留 Jacobian 修复使用的可行步长策略，以及实际使用的形状阶段接口。
- 阶段计时改为 `Options::profile` 显式启用，默认关闭；总耗时、取消和超时仍正常工作。关闭时分阶段指标为零，表示未测量。
- 障碍循环的时钟与取消轮询由每 32 个候选改为每 1024 个。区间、递归与 Newton 边界继续检查请求状态。
- 外部种子、地图及参数的校验保留在各自入口。SOC 定义域、求解分解、支持与全截面 Jacobian 判断随当前几何变化，是接受更新的条件，继续保留。

新增计时开关回归：相同输入下，两种模式的中心和形状控制系数精确相同；同时检查关闭模式没有阶段计时结果，开启模式产生计时。

验证采用串行构建与 CTest，单进程地址空间限制 4 GiB；并编译 ROS 演示入口以检查形状阶段接口。安装依赖库后重新构建调用端的日志见 [integration.log](validation/h5_cleanup/integration.log)。功能测试及首次集成检查日志位于 [checks.log](validation/h5_cleanup/checks.log)。本轮没有运行冻结地图的重复性能 Benchmark，不据此宣称具体提速百分比。

H5 的标架平滑、共享导数平滑、局部盒与全截面认证在演示配置中仍然使用，不按裸 `Options` 中的零值默认判断为无用功能。历史实验数据和报告继续保留。
