# C3 与 H5 配置及库结构整理

本轮按配置拆分、H5 默认入口收敛、C3 正式库化的顺序整理。算法数值内核不变，同输入比较以原来的 C3 默认配置和 H5 smooth 为参照。

## 配置边界

| 类型 | 内容 |
| --- | --- |
| `GeometryOptions` | 机器人尺寸、地图膨胀、截面尺寸、节点间距、参考标架平滑尺度、证书和资源上限 |
| `native::CubicOptions` | C3 的几何输入，不包含 H5 导数平滑、迭代数、取消回调等字段 |
| `Options` | H5 几何输入及其平滑、求解和诊断参数 |
| `native::OptimizerSettings` | C3 固定算法常量和显式诊断开关 |

跨算法使用共同的几何输入时，显式构造 `CubicOptions(geometry)` 和 `Options(geometry)`。C3 不再隐式接收 H5 参数；演示保存 `GeometryOptions`，在选择生成器后才构造对应配置。

H5 默认值改为原演示的 smooth 设置：方向平滑 1.5、截面正则 0.2、导数平滑 0.01、全截面 Jacobian 认证开启、初始迭代数 8。新建 C3 配置的方向平滑默认值也与演示一致，为 1.5；显式从共同几何输入构造时保留调用者设置。

这意味着裸 `Options{}` 从原来的历史 H5 配置变为 smooth。低层历史测试和旧轨迹实验显式设置原参数，正常生成和 CLI/ROS 节点采用新默认值。此次一致性比较针对既有 smooth，而不是要求新默认值复现历史零导数版本。

## 正常入口

交互演示保留 `shape_mode:=c3` 和 `shape_mode:=smooth`。移除 `baseline`、`boundary-12` 选择及 shape refit 库依赖，历史算法仍可在独立实验中研究。演示不再声明迭代预算覆盖参数，也不再启动一次虚拟 H5 求解做预校验；真实请求由选中的生成器统一检查输入。演示在启动入口检查自身预处理会使用的局部扩张范围和分段长度，避免在调用生成器之前消费非法参数。

## 库结构

- `direct_corridor/include/gcopter/cubic/`：公开几何、生成接口、配置、指标及证书。
- `direct_corridor/src/cubic/`：优化、构造、障碍覆盖与诊断实现。
- `direct_corridor/experiments/native_splines/`：测试、比较程序和脚本。
- `gcopter::direct_corridor`：安装导出的 H5 target。
- `gcopter::cubic_corridor`：安装导出的 C3 target，复用 H5 库中的地图与公共几何基础设施。

C3 的公开生成头文件不再包含私有优化器和障碍构造实现。支撑平面数据单独放在公共头文件中，避免为数据类型包含完整 H5 生成流程。ROS 与 benchmark 链接同一个 C3 库目标，不再各自维护源码列表。

C3 优化器仍保留四控制点带状结构，H5 保留自己的节点优化结构。投影质量参照、连续安全证书、轨迹工具和历史验证资料均保留。诊断实现本轮随 C3 库构建，独立诊断 target 不在这三项改动范围内。

## 验证

使用 `fc5b1ea` 清理后的冻结二进制作为参照。C3 比较 67 组固定输入，H5 smooth 比较七组开发输入；每组预热一次、正式三次，串行、单数值线程、4 GiB 地址空间限制。验证记录位于 `validation/corridor_library_cleanup/`。

验证结果：

- C3 的 8 项测试、H5 回归测试均通过。
- C3 67 组状态一致：65 组成功、2 组预期初始化失败。成功用例的几何系数、支撑平面逐字节相同，Newton 决策统计一致。
- H5 smooth 七组输出系数逐字节相同。
- 独立安装包消费者通过配置类型静态检查，C3/H5 均返回成功。测试工程在 `direct_corridor/tests/installed_consumer/`，不使用源码私有 include 路径。
- 实验 benchmark、轨迹后端、ROS 库和交互演示编译通过，ROS 安装已更新。本次没有启动 RViz，也未运行轨迹优化。

本轮属于接口和构建结构整理，不将短测计时波动解释为算法提速。输出几何相同，因此已有 C3 和 H5 smooth 配置的体积与边界平滑性保持不变。

```bash
cmake -S direct_corridor/tests/installed_consumer \
  -B .scratch/installed_consumer \
  -DCMAKE_PREFIX_PATH=/absolute/path/to/installed/prefix
cmake --build .scratch/installed_consumer -j1
.scratch/installed_consumer/consumer
```
