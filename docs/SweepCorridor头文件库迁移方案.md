# SweepCorridor 头文件库迁移方案

基于 `92da988` 的 C3/H5 整理结果，将默认生成内核迁移为可独立复制的 C++17/Eigen 头文件库。名称 SweepCorridor 对应 `F(u,z)=c(u)+M(u)z, ||z||≤1` 的扫掠几何。

## 接口与结构

- 对外提供 `Corridor<3/5>`、`Generator<3/5>`、相同的 `section()`、`evaluate()` 查询接口。
- 输出统一为分段 Bézier 中心和截面控制量，次数在编译期确定；C3 不升阶用于常规查询。
- 共用障碍索引、几何、支撑平面与证书基础设施；保留 C3 带状优化与 H5 节点优化专用内核。
- 公共配置仅描述几何、资源与显式诊断。默认算法常量留在各自内核，安全认证不能关闭。
- 独立包只依赖 Eigen，无 ROS、GCOPTER、文件 I/O、环境变量或轨迹优化依赖。
- CMake 使用 INTERFACE target，支持 add_subdirectory、安装后 find_package 和直接复制 include 目录。
- ROS/CSV/绘图属于仓库外层适配；数值诊断、投影质量参照和历史实验不进入生产包。

## 迁移步骤

1. 冻结当前二进制和输入，先提交已完成的整理及验证。
2. 建立统一几何与查询接口，迁移默认 C3/H5 内核为 ODR 安全的头文件实现。
3. 清理历史模式、ShapeStage 可变回调和无效配置，支撑平面通过显式结果导出。
4. 更新正式调用方与构建，去掉重复实现。历史结果保留，旧代码可从冻结提交恢复。
5. 验证数值导数、多翻译单元、独立安装消费及同输入几何/性能。

## 验收

串行构建和运行，4 GiB 地址空间、单数值线程；冻结地图和种子路径。先比较几何系数和连续证书，再报告生成耗时与内存。保持默认 C3 与 H5 smooth 的生成行为，不以删除验证或改变收敛预算换取速度。

查询契约：`evaluate(u,x)` 返回截面约束值、梯度、Hessian 和平面残差；约束值非正不能单独说明点在走廊内。只读走廊可共享，查询缓存由调用者独立持有。
