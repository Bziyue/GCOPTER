# 直接 B 样条走廊：模型、算法与安全边界

> 历史阶段记录：以下实现或计时对应旧版 B 样条/离线实验。当前主生成器和 ROS 演示已使用 [五次 Hermite](五次Hermite走廊.md)，最新结果见 [验证报告](Hermite走廊验证.md)。交互启动方式保持一致。


状态：已实现的第一版；从 `Bziyue/GCOPTER` 的 `ros2` 提交 `5f44faf88c486cb39dbd087afa3dbfb837fad05d` 新建分支。模块独立于原 GCOPTER 的 FIRI / SFC / 轨迹优化链路。构建入口见 [模块 README](https://github.com/Bziyue/GCOPTER/blob/62645e2/direct_corridor/README.md)。

## 目标与取舍

输入：同一 Cartesian world frame 下的有序种子折线、球体实体障碍、有限地图 AABB。输出：沿整条种子路径的 C² 椭圆截面扫掠、解析一二阶导数、连续几何验收结果。

本实现保留 CorrGen 的“连续椭圆族”思想，但不是原论文五个全局多项式 LP 的等价改写。采用世界坐标仿射截面，将光滑性和连续碰撞证书直接建立在 B 样条的非负基与局部支撑上：

- 不生成 FIRI 多面体序列；内部只为障碍/当前跨度计算分离方向并形成半轴约束。
- 不逐点寻找最近路径参数，也不假定障碍投影唯一。
- 不依赖完整规模 LP；控制方向固定后，半轴平方约束线性化，各控制截面独立优化。
- 中心线固定、控制截面无偏心；最终截面可能相对中心线法平面倾斜。这是性能、可证性与表达能力的明确取舍。

## B 样条表示与微分

令 Bᵢ(u) 为均匀三次 B 样条基，内部简单节点；任何 u 只涉及四个控制量，且 Bᵢ≥0、ΣBᵢ=1。

```
c(u) = Σ Bᵢ(u) cᵢ
M(u) = Σ Bᵢ(u) Mᵢ          Mᵢ ∈ R^(3×2)
x(u,v) = c(u) + M(u)v      ||v||₂ ≤ 1
```

cᵢ 来自细分后的种子折线，两端添加外推控制点，保证 u=0/1 精确保留原端点。中间折点允许圆滑化，但安全验证针对完整圆滑管道。重复相邻点清理；精确回折、无法认证的尖点失败。

控制方向由离散切向的最小旋转运输得到 Fᵢ=[fᵢ₁,fᵢ₂]，每个 Fᵢ 的两列正交归一。Mᵢ=Fᵢ diag(rᵢ₁,rᵢ₂)，方向固定，半轴优化。若有 K 个控制截面，本版有 2K 个半轴变量；输出存储固定中心 3K 个数和最终形状矩阵 6K 个数。不是原 CorrGen 的 5K 个自由函数系数。

由于 c、M 都直接采用三次 B 样条，x(u,v) 对 u 是 C²；没有通过归一化切向标架引入额外连续性损失。`section()` 返回 c、M 及其对全局 u 的一二阶导数。`pieces()` 不同会改变全局参数缩放，代码明确乘入段数及段数平方。

对于指定截面和世界点 p，定义 P=M⁺=(MᵀM)⁻¹Mᵀ、z=P(p−c)，则 q=||z||²−1。`evaluate()` 返回 q 对 `[u,x,y,z]` 的解析梯度和 Hessian。属于截面还须满足 `(p−c)·normalize(M₁×M₂)=0`，接口同时返回米制平面残差。**仅检查 q≤0 会得到一个无限柱体，不足以判断走廊成员资格。** 本接口不做世界点的唯一 u 反解。

## 直接障碍约束和整段证书

障碍为闭球 S(o,R)，R 加上机器人半径、安全余量与数值保护。对一个跨度内四个中心控制点的凸包，选择指向远离障碍的单位方向 n：优先使用平均中心方向；净空不足时，计算球心到四点凸包的最近点方向。

要求该跨度的每个控制截面满足：

```
n·(cᵢ−o) − ||Mᵢᵀ n||₂ ≥ R
```

对于同一跨度内任意 u、任意 ||v||≤1：

```
n·(x(u,v)−o)
= Σ Bᵢ [n·(cᵢ−o) + n·Mᵢv]
≥ Σ Bᵢ [n·(cᵢ−o) − ||Mᵢᵀn||]
≥ R
```

因此整个连续跨度都在球外的同一半空间中。一个控制截面参与多个跨度时，合并这些跨度的全部约束。地图六个边界也使用同样的支撑约束。

该证明覆盖截面内部和跨度内部，不依赖显示采样、障碍最近投影或碰撞抽样。成功前重新检查未平方的支撑残差。超时或未能证明时不发布输出，不做全局半径缩小兜底。若控制凸包过于保守，则缩小种子细分间距重新构造，受细分、容量和总预算上限约束。

球体是一种明确的实体输入模型，不是对稀疏点云表面的自动重建。体素可以用外接球覆盖，代价是保守性；薄缝通过能力不能与精确体素盒检查等同。ROS 适配器先体素化点云，再用外接球覆盖占据体素。

## 局部半轴优化

设 Aᵢ=rᵢ₁²、Bᵢ=rᵢ₂²，d=n·(cᵢ−o)−R。必须先确认 d>0，随后上述约束变为：

```
(n·fᵢ₁)² Aᵢ + (n·fᵢ₂)² Bᵢ ≤ d²
min_radius² ≤ Aᵢ,Bᵢ ≤ max_radius²
maximize log Aᵢ + log Bᵢ
```

目标等价于最大化这个**控制椭圆**的面积。对给定 A，B 的最大可行值为各线性上界的最小值，是分段仿射凹函数。因此可用有界一维凹优化（48 步黄金分割）求解，不需要外部 LP/SOCP 依赖。无有效约束直接使用最大半轴。

这不是全局扫掠体积最优；控制椭圆的面积也不等于每个插值后截面的面积。`min_radius` 限制控制半轴，混合不同方向后实际截面短半轴可能更小；不应把它当作全程实际最小净空。

## 非退化验证

仅保证碰撞安全还不够，M(u) 可能因方向混合退化。对每个跨度计算多项式：

```
D(u) = c'(u) · (M₁(u) × M₂(u))
```

c' 为二次、M 两列为三次，D 最高八次。通过 Bernstein 乘积公式得到九个系数，用凸包下界和 de Casteljau 递归细分确认整段 D>正裕量。由此保证中心线切向非零、M 满列秩、中心线处截面横截性。

此证书**不证明**离开中心线后的完整映射 Jacobian 非零，也不排除整条管道自交或远处截面相交。它保证的是已声明的参数曲面光滑性、截面非退化和实体排除。全部证书使用双精度和数值保护，不是有向舍入形式化区间证明。

## 性能结构

- 球体 BVH 独立构建，可跨请求复用。按控制凸包 AABB 扩张 max_radius+机体余量查询；障碍自身半径已包含在 BVH AABB 中。
- 控制半轴不超过 max_radius、B 样条非负，因此扩张盒包含整段扫掠；BVH 裁剪不会因只查询中心线附近而丢失远端碰撞。
- 固定维数凸包最近点（最多四点）；半轴优化只访问相邻跨度产生的限制。
- 评价单个截面只读取四个控制量，长度增长不增加单次求值的矩阵维数。
- 生成成本取决于路径跨度数和局部障碍对；在所有障碍都靠近所有跨度的极端输入下，不承诺总线性复杂度。
- 核心预算覆盖生成而不覆盖索引构建；取消和超时为协作检查，不是硬实时调度保证。

## 与现有 GCOPTER 的边界

原 `gcopter` 包保持不变。新增模块提供直接几何走廊与导数；没有把原多面体轨迹约束替换成该管道，也没有改 MINCO/Spline 的动力学求解。后续若优化 u(t)、横向位置或完整世界轨迹，需要单独处理时间链式导数、推进条件和整段轨迹管内约束，不能只将原半空间残差替换成 q。

“可微”在此指走廊对几何参数/坐标的可微性，不表示包含路径细分、分离方向选择和约束活动集变化的**整个生成算法对输入地图可微**。
