# Hermite 第二轮加速：等价计算的代价

本文保留 `62bd104` 的结果，后续体积优化和缓存加速见[第三轮优化](Hermite第三轮优化.md)。

日期：2026-11-02。基线为 `e245bc4`，在其已有的极对偶约束化简、近障碍优先分离和数值稳定性处理上继续优化。

最终保留三项改动：提前计算椭圆距离变换、同半径障碍的平方距离排序、展开小矩阵导数并采用正定 Cholesky 块求解。六条路径的生成耗时降低 **8.6%–12.6%**；当前采样分辨率下，新旧版本的并集体积估计一致。未修改机器人尺寸、扩张盒、节点间距、膨胀轮数、每阶段迭代上限或安全认证条件。

## 1. 提前计算度量，同半径时比较平方距离

当前截面矩阵为 M，令 `MᵀM=UΛUᵀ`，截面法向为 n，纵向尺度为 ℓ。原优先级使用：

```text
q = Λ⁻¹ Uᵀ Mᵀ (o-c)
a = nᵀ(o-c) / ℓ
priority = sqrt(qᵀq + a²) - (r+pad)/s_min
```

其中 o、r 是障碍球心和半径。对同一曲面片，除 o、r 外均为常数。定义固定矩阵：

```text
W = [ Λ⁻¹ Uᵀ Mᵀ ]
    [      nᵀ/ℓ   ]
```

就可先构造 W，在逐障碍循环中只计算 `||W(o-c)||²`，避免每个障碍反复做相同除法。

当所有候选障碍半径相同时，`(r+pad)/s_min` 是共同常数，平方根又严格单调，因此：

```text
argmin priority = argmin ||W(o-c)||²
```

这个分支不需要逐障碍开方或半径除法。半径不同则恢复完整优先级，支持任意球体输入，不假设地图一定来自等大体素。

这些数值只决定处理顺序。接受分离平面、排除整个膨胀球、连续 Bézier 支持检查和末尾复核仍使用原来的双精度几何条件。提前计算会改变极小的舍入误差，但没有以距离排序替代碰撞判定。

## 2. 直接展开 2×2 对称矩阵导数

优化中反复计算 `-log det P`，P 为对称正定 2×2 矩阵。若：

```text
P⁻¹ = [ a b ]
      [ b c ]
```

以 `(P00,P01,P11)` 为坐标，其梯度与 Hessian 为：

```text
gradient = -[a, 2b, c]ᵀ

Hessian = [ a²       2ab          b²  ]
          [ 2ab      2(ac+b²)     2bc ]
          [ b²       2bc          c²  ]
```

由 `d log det P = tr(P⁻¹dP)` 和 `dP⁻¹=-P⁻¹(dP)P⁻¹` 可直接得到。旧实现对每对基矩阵反复计算矩阵乘积与迹；新版只计算一次行列式，再累加上述标量表达式。

新增测试用独立有限差分检查完整障碍目标的梯度和 Hessian，包含上下半轴边界、中心偏移、SOC 支持和相邻节点平滑项，不只检查这一公式的孤立实现。

## 3. 使用正定结构选择分解

当前子问题是凸障碍目标，加入中心锚定并固定端点自由度后，其有效牛顿 Hessian 正定。尺度平衡及相对阻尼保持该性质；块消元的 Schur 补在精确算术下也正定。因此使用无主元 Cholesky `LLT`，替代带对称主元选择的 `LDLT`。两者适用范围的区别见 [Eigen 官方分解说明](https://libeigen.gitlab.io/eigen/docs-master/group__TutorialLinearAlgebra.html)。

仍保持 5×5 块三对角结构，直接通过分解求解，不形成逆矩阵；保留相对阻尼重试、原目标回溯线搜索和完整约束复核。它不是任意不定优化问题的通用替换。此前暴露过问题的 Perlin 路径 9，以及 2000:1 轴比回归，本轮均通过。

## 尝试过但没有保留的方案

探索性试验使用三条原对照路径、每例五次计时和 131,072 个体积样本。这里记录整个版本的总耗时；运行噪声存在，不能把亚毫秒差别解释为稳定收益。

| 试验版本 | 交互路径 | Perlin 路径 10 | 迷宫路径 10 | 处理 |
|---|---:|---:|---:|---|
| 本轮初始基线 | 31.91 ms | 65.09 ms | 57.61 ms | 对照 |
| 连续复制候选球坐标 | 31.96 ms | 66.62 ms | 59.43 ms | 撤回 |
| 解析锥边界步长 | 31.18 ms | 66.92 ms | 56.20 ms | 未保留 |
| 锥步长 + 32 点包围盒分组 | 34.22 ms | 73.33 ms | 64.63 ms | 撤回 |
| 锥步长 + 保守混合精度 SIMD 筛选 | 31.36 ms | 65.97 ms | 56.94 ms | 撤回 |
| 预计算度量与同半径排序 | 28.81 ms | 58.72 ms | 51.93 ms | 保留 |
| 再加导数展开与重复支持值合并 | 28.36 ms | 59.28 ms | 53.48 ms | 仅保留导数展开 |
| 最终组合，Cholesky | 28.51 ms | 56.76 ms | 51.06 ms | 进入六例精测 |

解析步长利用 `(t+αdt)²-||z+αdz||²=0` 求二阶锥边界，相关方法见 [CVXOPT 锥规划说明第 8 节](https://www.seas.ucla.edu/~vandenbe/publications/coneprog.pdf)。它令迷宫体积估计增加约 2%，但本实现中遍历全部约束求步长的额外代价抵消了减少折半试算的收益，暂不并入默认求解器。

混合精度方案参考了图形学中“快速浮点计算 + 保守误差区间 + 精确回退”的思路，相关误差分析见 [PBRT 浮点误差章节](https://www.pbr-book.org/4ed/Shapes/Managing_Rounding_Error)。该试验对边界模糊情况回到原双精度判定，但整体没有稳定提速，因此最终代码没有保留它。包围盒分组也没有覆盖足够多的批量跳过场景。复制和额外计算可能抵消了收益；这属于对实测的解释，不是已完成的硬件计数器归因。

## 后续更值得验证的方向

1. **椭圆最近点的带保护 Newton 法。** 现有分离方向计算中，求解 `Σ b_i²/(λ_i+τ)²=1` 使用固定二分。该函数在 `τ≥0` 单调下降，可以用解析上下界结合 Newton 更新，保留二分回退和完整支持平面验收。应先单独计量它的占比，再决定是否替换，不能仅凭迭代次数预测收益。
2. **两轮膨胀之间复用候选障碍。** 当前查询包围盒由参考路径、标架及固定上限决定，在同一次请求的两轮膨胀间不变。可在固定内存预算内复用索引列表；需要限制缓存总字节数，并在参考几何或地图变化后失效。这一项尚未实现。

本轮没有通过减少节点、降低认证深度、减少优化迭代或缩小障碍球来获得加速。要进一步提高体积，仍需单独处理真实扫掠并集目标与当前节点 logdet 目标之间的差异；本轮成果是保留已有体积利用率并降低计算代价。
