# Hermite 走廊的约束化简、分离平面与数值优化

日期：2026-11-02。基线为提交 `661dd28` 的同范围版本。保持原地图、种子、3 m 局部盒、机器人尺寸、认证余量、0.4 m 节点间距和两轮膨胀，修改内部算法。所有构建与验证串行执行。

本轮三条实体障碍样例中，**并集体积增加 15.6%–28.1%，生成加速 3.20–3.87 倍**。保存的 26 条路径全部通过。复杂转弯样例的体积超过 FIRI，但三例生成速度仍未超过 FIRI。

FIRI 列沿用“原算法 + 同安全距离收缩 + shortCut”，不是声称原算法直接接受球体障碍。体积是空间并集，重叠只计一次；± 为采样估计的近似 95% 半宽。

## 1. 用极对偶删除冗余约束

节点截面在自身二维坐标中写成 `y=d+Sv, ||v||≤1, S≻0`。一个只作用于该节点的支持约束为：

```text
aᵀd + ||Sa|| ≤ h
```

它等价于整个椭圆包含于半平面 `aᵀy≤h`。选当前严格可行的中心 `d₀`，定义：

```text
q_j = a_j / (h_j - a_jᵀd₀)
```

若 `q_i` 位于 `conv({0,q_j:j≠i})` 内，就存在非负系数 `λ_j`，满足 `q_i=Σλ_jq_j`、`Σλ_j≤1`。于是对于满足其余半平面的任意点：

```text
q_iᵀ(y-d₀) = Σ λ_j q_jᵀ(y-d₀) ≤ Σ λ_j ≤ 1
```

因此这一半平面冗余，相应的椭圆支持约束也对**任意中心和形状**冗余。这是几何可行集合的等价化简，不是根据当前松弛量猜测非活跃约束。

实现按节点构造二维极对偶凸包，仅剔除有数值余量的严格内部点；共线、贴边和耦合两个节点的约束保留。所有原始约束仍保存，求解后逐项复核。第一项消融中，求解约束由约 2–4 万条降至 2–4 千条，优化阶段从 64–120 ms 降至 12–20 ms。

有限障碍参数下，删除冗余行也会改变对数障碍项的权重；结合有限迭代和下一轮分离平面更新，输出不必与旧版完全相同。单独采用这一步时，迷宫体积曾下降约 3%，因此没有把“等价可行集合”误写成“有限迭代输出体积必然不变”。

## 2. 优先处理近处障碍，并复用已经成立的分离证书

旧版本为大量障碍分别计算椭圆最近点，再合并量化方向。新的算法受 [Deits 与 Tedrake 的 IRIS 方法](https://groups.csail.mit.edu/robotics-center/public_papers/Deits14.pdf)启发：使用当前截面的椭圆度量排序，优先处理近处障碍，建立实际法向的分离平面，并排除已经位于该平面背后的球体。这里是针对连续 Hermite 曲面片的实现，不调用 IRIS 或 FIRI，也不继承其单椭球体积单调性的结论。

对单位法向 `n` 和平面 `nᵀx≤h`，必须先检查该片全部六个 Bézier 控制椭圆：

```text
max_j [nᵀc_j + ||M_jᵀn||] < h
```

Bézier 权重非负且和为一，因此整段扫掠均在平面内。对另一障碍球，中心为 `o`、半径为 `r`，机器人及安全余量为 `ρ`，只有满足

```text
nᵀo - r - ρ ≥ h
```

才可以跳过后续最近点计算。这检验的是整个膨胀球，而不只是球心。不能分离的障碍仍进入 de Casteljau 细分认证。

排序只影响启发式效率；安全来自上述两个独立条件。每个候选障碍都有直接证书，或被已有平面覆盖，或继续细分，没有因为距离远或方向接近就直接丢弃。实际法向也避免了原方向量化带来的部分额外限制。

计算上，将“大量障碍各做一次非线性最近点求解”改为“少量前沿障碍求解，其余进行点积与半径比较”。若候选数为 M、选出的平面数为 K，主要筛选代价约为 O(MK)，不能保证任意环境都线性或更快。本轮地图中 K 远小于 M，证书阶段明显下降。

最终实体样例的开销分解如下，阶段时间取最后一次生成内部统计，因此与中位总时间可能略有差异：

| 路径 | 证书阶段：旧 → 新 | 优化阶段：旧 → 新 | 求解约束数：旧 → 新 |
|---|---:|---:|---:|
| 交互路径 | 55.6 → 16.8 ms | 64.4 → 13.7 ms | 19,622 → 1,972 |
| 23 转弯路径 | 115.2 → 42.1 ms | 119.3 → 22.2 ms | 38,215 → 3,363 |
| 迷宫路径 | 85.5 → 38.9 ms | 90.4 → 15.9 ms | 25,503 → 2,699 |

## 3. 改善牛顿求解的精度和数值条件

原求解器每个障碍参数阶段最多 8 次牛顿迭代；三条对照路径都用满该限额。本轮提高至 12 次，在仍明显快于旧版的情况下恢复更多截面面积。仍有迭代上限，不声称达到完全收敛或全局最优。

完整回放暴露了一例矩阵分解失败。紧约束令对数障碍 Hessian 的不同方向尺度差异很大，显式逆及 Schur 补消元会放大舍入误差。现在采用对角平衡：

```text
D = diag(sqrt(diag(H)))
(D⁻¹ H D⁻¹ + λI) z = -D⁻¹ g
Δx = D⁻¹ z
```

保留 5×5 块三对角结构，通过 LDLT 分解直接求解，不显式形成逆矩阵。若分解失败，使用递增的相对阻尼重试，最大到 `1e-4`；失败仍明确返回错误。步长由原目标的回溯线搜索验收，安全约束和末尾完整复核不变。修复后 26/26 条保存路径通过，并增加了 2000:1 截面轴比的解析空通道回归。

## 4. 尝试过但未采用的体积目标

单个二维截面面积为 `A=π det S`；最大化 `log det S` 是标准的最大体积椭球目标，可参考 [Vandenberghe、Boyd 与 Wu 的行列式最大化研究](https://web.stanford.edu/~boyd/papers/maxdet.html)。但跨节点求和 `Σ log det S_i` 并不等于走廊并集体积。

对扫掠映射 `x(s,v)=c(s)+M(s)v`，其有向 Jacobian 为：

```text
J(s,v) = (c′(s)+M′(s)v) · (m₁(s)×m₂(s))
∫_{||v||≤1} J(s,v) dv = π c′(s) · (m₁(s)×m₂(s))
```

第二式来自圆盘一阶矩为零。这是有向参数体积；只有满足相应的 Jacobian 符号及不重复覆盖条件时，才可当作几何体积。当前只认证中心横截性，不保证整管映射一一性，因此必须继续用并集归属法评估实际体积。

本轮尝试对节点面积乘弧长权重，利用 `exp(z)≥exp(z₀)(1+z-z₀)`，将面积和替换为相切的加权 `log det S` 下界，保持每个子问题凸。但该代理仍没有准确表达段内变化、截面倾斜和自重叠；当前有限迭代下，实测三条路径的并集体积均下降，已撤回。

探索性消融使用每例 131,072 个采样点，数值比最终测量更粗：

| 方案 | 交互路径体积 | 23 转弯体积 | 迷宫体积 |
|---|---:|---:|---:|
| 仅极对偶化简，8 次/阶段 | 392.1 m³ | 543.7 m³ | 354.6 m³ |
| 再加入近障碍优先分离，8 次/阶段 | 403.7 m³ | 594.7 m³ | 397.8 m³ |
| 再加入面积加权代理，8 次/阶段，撤回 | 400.1 m³ | 577.3 m³ | 371.7 m³ |
| 近障碍优先分离，12 次/阶段 | 416.8 m³ | 625.1 m³ | 421.7 m³ |

后续若继续优化体积，更有依据的方向是对段内 Jacobian 积分构造局部模型，并用信赖域及实际几何指标验收；必须处理重复覆盖，不能直接用有向体积替代并集。当前保留了已经验证有效的约束、证书和数值求解改进。
