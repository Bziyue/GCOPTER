# C3 默认配置收敛清理

本次只保留当前默认 C3 生成算法。删除 Fast、Volume 预设和 Balanced 选择器；默认行为直接成为唯一实现。

## 清理内容

- 删除 `NativePreset`、`applyNativePreset()` 以及预设参数。
- 删除 benchmark 中能量权重、迭代预算、预测比例、体积扩张次数等环境变量覆盖入口，以及运行脚本的对应参数。
- 将算法常量集中在 `OptimizerSettings` 中，固定两轮生成、默认 Newton 预算、预测步和一次认证体积扩张。去掉为其他配置保留的分支和固定常量的输入检查。
- 保留机器人尺寸、地图范围、节点间距、证书深度、超时等问题输入。保留显式 `profile` 和梯度诊断，正常生成仍关闭细分计时。
- C3 演示不再声明无效的 `inflation_iterations` 参数；该参数仍属于独立 H5 入口。
- 删除只服务于历史多预设比较的 `analyze_cleanup.py`。历史代码与结果可从 `4377eab` 及已有归档恢复。

H5 对照和 C3 投影质量参照仍是独立实验工具，不属于原生 C3 的运行预设。本次不删除历史实验结果。

## 验证方式

冻结清理前的默认生成二进制，与清理后程序使用相同的 67 组地图/路径。每组预热一次、正式运行三次，串行运行，单数值线程、CPU 2、4 GiB 地址空间上限。比较成功/失败状态、17 位精度几何系数导出与支撑平面 SHA256；连续安全认证及独立新地图检查沿用现有 benchmark。

基线二进制来自 `884f9cd` 的 C3 清理构建；随后 `4377eab` 只修改 H5，C3 生成代码未变。结果归档见 `validation/c3_default_only/`。本次以默认行为一致为验收标准，不把短测计时波动视为性能收益。

验证结果：8 项测试全部通过；67 组输入状态一致，其中 65 组成功、2 组预期初始化失败。成功用例的几何系数与支撑平面逐字节相同，Newton 决策统计一致，因此走廊体积和边界平滑性保持不变。

原生库、benchmark、轨迹后端编译通过；RViz2 交互演示已重新编译并安装，本次未启动可视化程序。
