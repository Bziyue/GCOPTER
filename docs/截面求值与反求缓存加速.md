# 截面求值与反求缓存加速

## 范围和正确性边界

基于 `5a2d3ad`，优化同初值实验中的 Hermite 世界坐标轨迹后端。`PreparedCorridor` 是可复用的独立求值器；原 Corridor 几何、控制系数和连续碰撞证书没有改变。迁入的四个样条/L-BFGS 头未改动。

默认 `--tube-mode fast`：只计算截面值与一阶导数；共享 Bernstein 幂值，保留原累加顺序；缓存固定走廊的截面及法向一阶导数；复用一次 LDLT 分解；去掉同一根位置的重复求值；对完全相同的 `(p.x,p.y,p.z,hint)` 复用完整反求结果。

每个求解实例独占 2048 个几何槽和 1024 个查询槽，固定内存、哈希冲突覆盖旧槽。键按精确浮点值匹配，不做近似量化，不跨候选热启动根。原来的 16 次 Newton、回退区间选择、40 次二分、停止阈值与隐式梯度公式保留，缓存不把求解历史引入目标函数。入口只准备一次有效 Corridor；内部 unchecked 求值由原求根的参数范围流程保证。

`--tube-mode reference` 保留原完整二阶截面求值，作为基准和独立审计。`--tube-mode horner` 是预计算局部幂基的试验模式：更快，但浮点重排使既有非光滑反求/优化路径改变，部分失败用例的残差增加，因此未选为默认。试验原始记录中的模式曾命名为 fast，存档已另加实现说明。

## 验证

- 5 个 CTest 通过；新增曲线节点、端点、内部/外部截面查询与精确缓存测试。
- 窄管局部测试：Horner 值/一阶导数误差最大 3.10e-14；默认 fast 的反求输出与 reference 差异为 0；空间梯度有限差分最大绝对误差 4.09e-6。有限差分步长为 1e-4，避免原有 1e-8 求根停止误差主导差分。
- 宽弯管中已观察到多根分支切换，跨分支差分不能验证局部隐函数梯度。这是 reference 也存在的现象，本次缓存不修复它，也不宣称全空间光滑。
- 六个冻结输入均检查完整目标梯度，两种走廊均通过相对误差 1e-4 门槛。正式计时每种方法先预热一次、重复三次。
- 默认 fast/reference 的目标、迭代数、评估数、初值哈希、时长、长度、jerk 能量、全部动力学和空间残差、可行性判定逐项一致；初始航点及两种走廊的轨迹 CSV 逐字节一致。哈希证据见 `validation/section_acceleration/trajectory_equivalence.json`。
- Hermite 原有 1/6 采样可行率没有改变。本次是等价加速，没有把不满足约束的候选重新标为安全。

## 分阶段计时

单独使用 `--profile` 运行，避免把每个查询的时钟开销计入正式速度比较。下表取 case_00 的计时轮；单位 ms。

| 阶段 | reference | fast |
|---|---:|---:|
| 完整目标评价 | 2452.27 | 1046.31 |
| 积分代价回调 | 1063.57 | 508.18 |
| 其中：动力学回调 | 75.59 | 74.62 |
| Bézier 系数代价回调 | 1355.66 | 505.43 |
| 样条更新、伴随、基函数累加、映射等其余工作 | 33.04 | 32.71 |
| 截面反求总计，跨积分/系数阶段 | 2242.61 | 838.28 |
| 其中：截面求值/缓存查找 | 1743.59 | 574.45 |

这些阶段有包含关系，不能相加。`spline_mapping_other_ms` 是总时间减去积分和系数回调时间，**不是单独测得的伴随耗时**。fast 的截面计时还包括缓存法向构造，reference 的法向构造计在反求的其余时间中。

case_00 查询次数相同，均为 2,175,624；fast 精确查询缓存命中 230,126 次。截面调用从 8,235,195 降至 5,443,553，其中 637,758 次复用已算几何。结果支持优先优化几何反求，而不是优先替换样条伴随。

## 资源与复现

构建串行，虚拟地址空间上限 3 GiB；每个地图实验串行、单线程、512 MiB 地址空间、55 s CPU / 60 s wall 上限。所有输入 SHA256、二进制 SHA256、原始质量和计时记录保留于 `docs/validation/section_acceleration`。阶段计时和正式计时分开记录。

```sh
prlimit --as=3221225472 --cpu=180 cmake --build .scratch/trajectory_comparison/build --target trajectory_comparison tube_query_test -j1
python3 gcopter/experiments/trajectory/run.py --inputs gcopter/experiments/trajectory/inputs.json --output .scratch/section_acceleration/reference --repeats 3 --check-gradients --tube-mode reference
python3 gcopter/experiments/trajectory/run.py --inputs gcopter/experiments/trajectory/inputs.json --output .scratch/section_acceleration/fast --repeats 3 --check-gradients --tube-mode fast
# 分阶段统计在对应命令中加 --profile，并使用独立输出目录。
```
