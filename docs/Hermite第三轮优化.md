# Hermite 第三轮优化：球障碍度量分离与查询复用

日期：2026-11-02。基线为 `62bd104`，所有输入、安全距离、局部扩张盒、控制间距、两轮膨胀、72 步牛顿上限均保持一致。

本轮六例**并集体积估计增加 1.16%–2.14%，生成耗时降低 10.7%–17.6%**。收益是小幅扩大体积，同时减少计算；没有得到全局最大体积保证。六例中四例比同期 FIRI 更快，两条迷宫路径仍较慢。

## 1. 球障碍在椭圆度量下的分离方向

旧实现先求障碍球心到中点截面椭圆的欧氏最近点，用两者差向量作分离方向。这能提供有效平面，但未直接考虑当前椭圆的伸展方向。

新版在第一轮优化得到形状后，构造中点的三维辅助椭球：截面两个主轴的平方长度为 `d0, d1`，第三轴是截面法向，平方长度 `d2 = ℓ²`，其中 `ℓ = max(半段端点距离, min_radius)`。它只用于选择平面，不是输出走廊，也不代替 Bézier 证书。

设主轴坐标下球心相对截面中心为 δ，`D = diag(d0,d1,d2)`，膨胀球半径为 `R = 障碍半径 + 机器人半径 + 安全距离 + 认证余量`。球在该度量下的最近点问题为：

```text
minimize    1/2 qᵀ D⁻¹ q
subject to  ||q-δ|| ≤ R
```

对球心距离大于 R 的情况，由 KKT 条件可得一个正标量 t：

```text
q_i = d_i δ_i / (d_i + t)
v_i = (D⁻¹ q)_i = δ_i / (d_i + t)
Σ [t δ_i / (d_i + t)]² = R²
```

方程左侧在 `t ≥ 0` 单调增加，根的界为：

```text
R min(d_i) / (||δ||-R) ≤ t ≤ R max(d_i) / (||δ||-R)
```

因此最多做 8 次带区间保护的 Newton 更新即可提出候选方向。将 v 转回世界坐标并归一化得到 n，球的支持平面为 `n·x ≤ n·o-R`。这借鉴了用椭球坐标选择分离面的思路，背景可见 [IRIS 原论文](https://groups.csail.mit.edu/robotics-center/public_papers/Deits14.pdf)；这里的球体一维 KKT 化简及接入方式是本模块的具体实现。

接受该方向前，仍对整个 Bézier 段的六个控制椭圆计算：

```text
max_j [n·c_j + ||M_jᵀ n||] < n·o - R
```

这是一项必需的几何判定：辅助椭球和近似根本身不保证整段走廊分离。若未通过，继续使用原欧氏方向；仍不能分离则按原流程细分。没有增加更密的离散碰撞采样，没有改变障碍膨胀距离。

**仅在后续膨胀轮使用该度量。** 初始微小圆截面尚不表达空闲空间形状。三例试验显示，从第一轮就使用点度量方向，体积损失 10%–26%；加入球半径后仍有两例回退。先完成原第一轮，再使用学到的形状，才同时得到体积与时间收益。默认膨胀仍为两轮，不是通过增加迭代取得收益。

## 2. 复用流程保证不变的查询数据

在同一次参考路径构造中，节点 reference、frame、局部盒和全局半轴/偏移上限不随形状优化改变，所以障碍 BVH 查询边界不变。新版：

- 同一段在后续膨胀轮复用候选索引，不再次遍历 BVH。
- 相邻段的查询盒完全相同时，按六个边界坐标精确匹配，共享一份索引。
- 候选索引缓冲按 vector 容量计费，上限 16 MiB；满后正常查询，不丢障碍。映射表及段索引是额外的 O(节点数) 元数据。
- 缓存由 generate 内当前参考构造持有；更换请求或进行参考路径细化时自然销毁。无需反复检查地图版本、数据哈希或几何是否变动。公共 API/ABI 不变。

定位使用独立 `-pg` 构建，对 Perlin 路径 10 连续生成 120 次，采样热点约为：分离与剔除 45%、BVH 查询 18%、目标/导数计算 13%。硬件 perf 被主机权限禁止；这些比例仅作定位，正式计时来自原 Release 构建。

## 3. 去掉冗余的热循环检查

核心原本已在 `ObstacleIndex` 构造时校验障碍、在 `generate` 入口校验路径和选项，本轮没有往内部添加数据格式或有限值检查。

- 删除每个 5×5 牛顿块分解前的 `allFinite()` 扫描；保留分解结果、相对阻尼和接受步的目标判定。
- 分离循环从每个候选都查询时钟/取消回调，改为每 32 个选中候选一次。函数入口、段/细分入口、牛顿迭代及最终出口仍有协作式预算检查；它不是硬实时截止保证。
- 保留更新后几何的支持平面判定、障碍排除证明、完整约束残差及非退化证书。这些判断对应变化的优化状态，不属于反复校验同一输入。

## 消融与未保留方案

试验使用前三条路径，每例预热一次、重复五次；QMC 每次平移 131,072 点，共 1,048,576 点。下表每格为“毫秒 / m³”，小差异不能视为稳定提速。

| 方案 | 交互路径 1 | Perlin 路径 10 | 迷宫路径 10 |
|---|---:|---:|---:|
| 本轮基线 | 28.48 / 418.29 | 58.97 / 626.09 | 51.59 / 421.46 |
| 段缓存 + 检查降频 | 26.14 / 418.29 | 53.57 / 626.09 | 47.49 / 421.46 |
| 从第一轮用点度量平面，撤回 | 20.99 / 356.21 | 39.77 / 464.09 | 27.11 / 378.95 |
| 从第一轮用球度量平面，撤回 | 22.71 / 402.89 | 43.41 / 571.24 | 30.61 / 421.56 |
| 仅后续轮用球度量平面 | 25.32 / 423.63 | 51.56 / 635.38 | 45.37 / 426.58 |
| 再用标准二阶锥障碍函数，撤回 | 25.18 / 423.58 | 52.01 / 630.12 | 45.94 / 427.01 |
| 再加弧长/面积权重，撤回 | 24.55 / 423.41 | 51.00 / 634.67 | 44.24 / 427.74 |
| 权重 + 原障碍函数，撤回 | 25.23 / 423.49 | 52.28 / 634.30 | 46.63 / 427.77 |
| 最终：再共享相同查询盒 | 25.27 / 423.63 | 49.71 / 635.38 | 45.78 / 426.58 |

标准二阶锥障碍函数 `-μ log(t²-zᵀz)` 可去掉内层开方，其数学形式见 [UCLA 二阶锥障碍法讲义](https://seas.ucla.edu/~vandenbe/ee236b/lectures/barrier.pdf)。试验通过梯度/Hessian 与安全测试，但没有稳定的总耗时收益，Perlin 体积略降，未保留。

重加权试验令 `w_i ∝ Δs_i det(P_i_previous)`，使用 `Σ w_i log det(P_i)`。指数函数的切线下界解释了它与截面积和的关系，但截面积积分不等于有自交时的扫掠并集体积。实测没有足够明确的额外收益，最终仍使用原目标，不增加这一启发式。
