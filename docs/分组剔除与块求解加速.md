# 分组剔除与块求解加速

基线为 `7d23370`，其生成器与 `abc0631` 相同。本轮继[参数化首轮实验](走廊参数化首轮实验.md)继续探索，最终接入两项计算优化：**沿 BVH 查询顺序对球体分组并缓存几何边界，以及复用块 Schur 消元结果**。

本轮主要收益是加速。六例同输入精测的并集体积估计保持一致，五例生成耗时下降约 **3.8%–9.3%**；交互路径 1 约下降 0.6%，接近计时噪声。未把实验中的局部体积增益作为默认实现的普遍收益。

## 最终同输入对照

每例两批、每批一次预热和七次重复，第二批交换新旧版本顺序。表中耗时为每个版本十四次生成的中位数。沿用实体球覆盖、同安全距离、3 m 局部扩张范围、0.4 m 控制间距、两轮膨胀和 72 步 Newton 上限。

| 路径 | 基线 → 新版 | 降低 | 新旧并集体积估计 | 同期 FIRI 耗时 |
|---|---:|---:|---:|---:|
| 交互路径 1 | 24.68 → 24.52 ms | 0.6% | 423.65 m³ | 29.81 ms |
| Perlin 路径 10 | 47.57 → 45.45 ms | 4.5% | 635.53 m³ | 56.50 ms |
| 迷宫路径 10 | 44.52 → 40.50 ms | 9.0% | 426.44 m³ | 37.49 ms |
| 交互路径 2 | 46.87 → 44.15 ms | 5.8% | 621.26 m³ | 53.45 ms |

| 迷宫路径 4 | 30.74 → 27.86 ms | 9.3% | 360.71 m³ | 23.36 ms |

每次体积统计为 8 次随机化 QMC 平移，每次 524,288 点，共 **4,194,304 点**；两批使用同一采样序列，不将重复统计当成更多独立样本。这里的“一致”指六例在该统计下得到相同数值，不是浮点控制系数逐位相同或体积的严格解析等值证明。近似 95% 误差半宽保留在[数据记录](validation/hermite_accel5.json)。

FIRI 沿用原实现及同实体安全距离收缩、shortCut；其球体安全、非空、连接与端点审计通过。新版仍有四例快于 FIRI，两条迷宫路径仍慢于 FIRI。时间不含地图读取、路径搜索、独立审计和体积统计；可复用 BVH 构建时间另计，分组缓存的当次构建包含在走廊生成时间内。

## 1. 用支持区间一次剔除一组球体

以前每接受一个分离平面，都扫描尚未排除的所有候选球体。新的实现沿 BVH 查询输出顺序，每 32 个球体形成一组，保留原始球体 ID。

设某组球心的轴对齐包围盒中心为 c、半尺寸为 e，组内球半径范围为 `[r_min,r_max]`。对已接受的单位法向平面 `n·x≤h`，每个膨胀球的最小投影是：

```text
d_i = n·o_i - r_i - pad
L   = n·c - |n|·e - r_max - pad
U   = n·c + |n|·e - r_min - pad
L ≤ d_i ≤ U
```

由此得到三个分支：

- `L ≥ h`：整组球体都在已证明安全的平面外侧，可以一次排除。
- `U < h`：本轮没有球满足排除条件，整组保留，继续使用其缓存的最近候选。
- 其余情况：仅对该组尚存的球体执行原逐球判定。

整组判定带有累计舍入余量，量级包含包围盒坐标、半径、pad 和平面偏置。边界不确定时执行逐球判定。包围盒只用于证明整组可剔除，**约束对象仍是原球体列表**；这与上轮研究的精确体素盒模型替换是两件事。

活跃候选用位掩码表示，不反复移动候选数组。每组保存当前最小排序距离，选择下一候选时组合这些最小值；不使用逐球优先队列。候选距离仍仅决定处理顺序，接受平面仍需通过全部 Bézier 控制截面的支持检查。

六例的显式逐球检查减少约 **72%–79%**。这不包含新增加的整组边界比较，也不是总时间下降比例；目标函数、线性系统和其他认证工作仍然存在。

### 生命周期与内存

组内球体及边界在同一地图、同一查询盒下不变，随候选索引一起缓存；相同查询盒的相邻曲段和后续膨胀轮共享这些几何数据。每次分离只复制活跃状态，缓存本身不被候选剔除修改。

候选 ID 和分组数组按实际 vector 容量**共同计入 16 MiB 缓存额度**，映射及曲段索引为额外 O(节点数) 元数据。额度满时正常查询并使用临时分组，不省略障碍；参考路径细化或新请求自然重建缓存。递归细分的失败子集使用其自身分组。

没有新增逐球输入格式或有限值校验。不可变输入仍在索引构造/生成入口处理；组的投影边界判断是当前分离步骤所需的几何计算。

## 2. 复用块 Schur 传递结果

对原 5×5 块三对角系统，令消元后的块为 S_i、右端项为 b_i，上非对角块为 U_i。缓存：

```text
G_i = S_i⁻¹ U_i
z_i = S_i⁻¹ b_i
x_i = z_i - G_i x_(i+1)
```

这些量通过原 Cholesky 因子求解得到，不形成显式逆矩阵。原实现已经在前向消元中计算过相同类型的解，回代时又进行一次三角求解；缓存后回代使用小矩阵乘法。

保留原对角平衡、相对阻尼重试、目标函数、回溯接受条件和完整约束残差。重试时从原系统重新计算，不复用上一轮失败的消元状态。额外存储为 O(节点数) 个固定小矩阵。

### 解析可行步长

沿 Newton 方向，支持约束为 `t(α)>||z(α)||`。t、z 都对 α 仿射，因此 `t(α)²-z(α)ᵀz(α)` 是二次多项式；形状矩阵的 2×2 行列式和中心偏移范数界也都是二次式。可以先求首次到达边界的步长，再乘 0.99 保持内点，最后执行原目标下降检查。

这减少了部分回溯浪费，也改变固定 72 步预算下的优化轨迹。从第一轮就使用时，一例体积下降。限定到第二轮，在前三例中改善较小；与分组、Schur 缓存合用做六例补测后，体积变化为约 −0.05% 到 +0.37%，主要增益集中于 Perlin 路径 10。其余多接近数值体积估计误差，未表现出普遍体积增益，最终未接入默认实现。

这仍是可研究方向：更准确地处理可行步长不等于更快达到同一收敛精度，更不保证并集体积增长。当前节点 logdet 目标与最终扫掠并集体积也不是同一个量。

### 按需距离与优先队列

用分组的椭圆度量距离下界延迟计算球体距离，数学上可减少排序距离评价；但逐球堆引入大量维护操作和重复平面过滤，两例明显变慢。只对组建堆改善了开销，仍没有稳定优于简单分组最小值扫描。最终采用结构更简单的位掩码与组最小值。

新三次样条、光滑 Minkowski 截面、正交标架及精确体素盒仍保留在此前的研究阶段；本轮没有声称这些新参数化已经接入完整生成器。
