# 五次 Hermite 可微走廊（当前实现）

本次替换了 `direct_corridor` 主生成器，ROS2 原地图/原搜索演示也使用同一实现。历史 B 样条实现及离线表示实验的报告保留用于对照。本实现不是原论文作者的实现，也不调用 GCOPTER 的 MINCO 轨迹优化器。

## 几何与优化自由度

输入是有序、无碰撞的种子**折线**。按弧长重采样并保留明显折点，再构造分段五次 Hermite。每个节点优化 5 个量：截面平面内中心偏移 2 个，正定对称 2×2 形状矩阵 3 个。首末中心固定在用户选择的端点。矩阵的非对角元允许椭圆主轴旋转；不再把两个半轴绑死在原先的运输标架上。

设参考节点位置为 `p_i`、运输标架为 `F_i`（3×2），变量为偏移 `d_i` 和正定矩阵 `S_i`：

```
c_i = p_i + F_i d_i
M_i = F_i S_i
x(u,v) = c(u) + M(u)v,   ||v|| <= 1
```

相邻段共享端点位置、一阶导、二阶导，因此世界坐标下的 `c(u)` 和 `M(u)` 均为 C²。参考切向量由相邻单位边方向的角平分线给出，避免不等长边的加权割线在急转弯处过冲；当前节点二阶导设为零，偏移和形状的一、二阶节点导数也设为零，以五次 smoothstep 连接。它是局部五次 Hermite 构造，**没有声称它是整条路径的全局最小 jerk 解**。

截面**平面法向**仍由参考路径运输标架给出，没有把每个节点的 SO(3) 姿态作为独立非凸变量。此次释放的是中心和椭圆主轴方向。段内世界矩阵连续插值，实际截面不必精确垂直于新的中心线。节点偏移上限默认 1.5 m，半轴上限默认 1.5 m；开阔空间仍受这些用户上限约束。中间种子点用于引导通路，允许平滑和偏移，不保证每个原始折点位于最终截面内。

优化目标主要是节点 `Σ log(det S_i)`，另有弱中心锚定和相邻变量平滑项。它鼓励扩大截面面积，但不等于扫掠体积的精确积分，也不提供全局最大自由空间解。

## Hermite → Bézier → 局部细分

每个 Hermite 区间转换为 **6 个等价的五次 Bézier 控制系数**，不是先拟合另一个 B 样条。对长度为 `h` 的区间，中心的参考系数为：

```
[p0, p0+h*v0/5, p0+2*h*v0/5,
 p1-2*h*v1/5, p1-h*v1/5, p1]
```

偏移与形状系数的右端节点混合权重是 `[0,0,0,1,1,1]`。de Casteljau 细分同时作用于参考系数和混合权重，不改变实际曲面。

每个障碍球与局部曲面片寻找分离平面。当当前片的六个控制椭圆无法整体分离时，只细分该障碍/曲面片对，直到能认证或达到深度上限。不会再要求跨越多个区间的原始 B 样条控制凸包落在同一自由区中。

对平面 `n·x <= b`，每个控制椭圆满足：

```
n·c_j + ||M_jᵀ n|| <= b
```

Bézier 权重非负且和为 1，因此这约束覆盖**整段、整个截面内部**。代入节点变量后得到仅耦合相邻两个节点的二阶锥约束。求解采用 5×5 块三对角牛顿系统。默认进行两轮“重建分离平面 → 扩张”；第二轮根据已偏移、已旋转的椭圆更新障碍方向。

加速措施包括复用障碍 BVH、按最大可达范围查询、缓存方向支撑值、合并同方向障碍平面与重复节点约束、利用二维范数 Hessian 的秩一结构直接累加小矩阵。方向合并前必须验证候选平面分离当前整片，不能因为量化方向而漏掉障碍。

## 安全与边界

- 输入球覆盖障碍实体；占据体素使用外接球。另加机器人半径、安全距离及默认 2 mm 认证余量。
- 原始折线的闭线段也检查碰撞。回折尖点、不能认证的净空或预算超限会明确失败，失败时输出为空。
- 输出前复核全部支撑约束；使用 14 次 Bernstein 多项式细分认证 `c'·(M0×M1)>0`，排除截面退化和中心切向穿越方向反转。
- `min_radius` 是节点矩阵特征值下界；不同标架混合后，段内最短半轴不保证恰好达到该下界。输出有单独非退化证书。
- 所有认证都是带数值余量的浮点计算，不是区间算术形式化证明。密集独立采样是回归检查，不能替代连续认证。
- 不保证整条走廊不自交，也不保证整管参数映射处处可逆。`evaluate()` 返回的椭圆二次型还须与截面平面等式联用。

“消除原先过大凸包导致的缩窄”不等于零保守。体素外接球、安全距离、椭圆截面族、有限细分深度和局部分离平面仍会限制空间利用率；不会通过削减机器人尺寸或关闭连续检查来制造更宽的图形。

## 输出格式 v2

`Corridor::hermiteNodes()` 提供节点状态；`knots()` 给出非均匀归一化区间。`centerControls()` 与 `shapeControls()` 现在是按区间排列的等价 Bézier 系数，每段六行。

CSV 和 ROS `Float64MultiArray` 每行 **11 列**：

```
u0,u1,cx,cy,cz,m00,m10,m20,m01,m11,m21
```

同段六行的 `u0,u1` 相同。在区间内使用 `t=(u-u0)/(u1-u0)` 与五次 Bernstein 基函数重建。ROS layout 标签为 `quintic_bezier_controls_v2`。旧版九列三次 B 样条解析器必须更新；演示、CLI、Python 绘图和端到端测试已同步修改。
